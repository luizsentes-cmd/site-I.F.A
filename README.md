# I.F.A - Inovação em Física, Robótica e Programação

Um site dedicado ao aprendizado e inovação nas áreas de **Física**, **Robótica** e **Programação**.

## 📁 Estrutura do Projeto

```
site-I.F.A/
├── index.html              # Página principal
├── contato.html            # Página de contato
├── css/
│   └── style.css          # Estilos globais
├── js/
│   └── script.js          # Scripts interativos
├── pages/
│   ├── fisica.html        # Página sobre Física
│   ├── robotica.html      # Página sobre Robótica
│   └── programacao.html   # Página sobre Programação
└── blog/
    └── index.html         # Blog com artigos
```

## 🚀 Como Usar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/luizsentes-cmd/site-I.F.A.git
   cd site-I.F.A
   ```

2. **Abra no navegador:**
   - Abra o arquivo `index.html` em seu navegador favorito

3. **Ou use um servidor local:**
   ```bash
   python -m http.server 8000
   # Acesse http://localhost:8000
   ```

## 📄 Arquivos Principais

- **index.html** - Página inicial com apresentação das três áreas
- **css/style.css** - Todos os estilos e responsividade
- **js/script.js** - Funcionalidades interativas

## 🎨 Recursos

- ✅ Design responsivo (funciona em desktop e mobile)
- ✅ Navegação intuitiva
- ✅ Cards interativos
- ✅ Animações suaves
- ✅ Formulário de contato
- ✅ Blog com artigos

## 🔧 Personalizações

Para customizar as cores, edite as variáveis CSS em `css/style.css`:

```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1e40af;
    --text-color: #1f2937;
    --light-bg: #f3f4f6;
}
```

## 📱 Deploy
